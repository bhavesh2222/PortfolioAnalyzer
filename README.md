# Portfolio Analyzer

## Overview

Portfolio Analyzer is a terminal-based portfolio management application built in Python. It uses live market data to analyze investments, track historical performance, and generate PDF reports.

## Features

- Add, edit, and remove assets
- Search and sort portfolio holdings
- Portfolio analysis
- Portfolio allocation
- Historical price performance
- Export portfolio analysis to PDF
- Persistent CSV storage
- Live market data using Yahoo Finance

## Technologies

- Python
- Object-Oriented Programming
- Rich
- yfinance
- ReportLab

## Installation

Clone the repository:

```bash
git clone https://github.com/bhavesh2222/PortfolioAnalyzer.git
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
